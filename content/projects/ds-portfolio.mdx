## The project
An ongoing personal journey into predictive machine learning, using food prices and grocery data as a practical place to learn, experiment, and grow.

## Current focus
I’m using this portfolio to learn predictive machine learning through hands-on work with food prices, grocery forecasting, and related datasets. It is an active learning project, and the repository is being built out incrementally.

## Learning goals
The project is a place to practice exploratory analysis, data preparation, forecasting workflows, and communicating findings clearly.
