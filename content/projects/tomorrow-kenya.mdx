## The project
Tomorrow Kenya is a public civic accountability platform built around a manifesto, a corruption tracker, and a petition experience. The live site frames those tools as a way to turn public concern into organized, trackable civic pressure.

## My role
Software development across the public-facing site and its interactive experiences. The project uses Next.js, TypeScript, Tailwind CSS, and Supabase, and is deployed on Vercel.

## The experience
The home page introduces the project, the manifesto collects its demands, the tracker organizes documented cases, and the petition section lets visitors add their voice.

## Outcome
One responsive website brings together the project's public message, accountability information, and participation flows. Visit the live site or source repository using the links on this page.

## Lessons learned
For civic software, clarity and trust are part of the product. Important data, calls to action, and context need to be easy to find and understand.
